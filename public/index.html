How a seal opens

  1. EncryptAES-256-GCM in your browser. The plain file never leaves this device.
  2. SplitThe key becomes N wrapped parts; K are needed. No holder can read a part.
  3. LockNEAR stores the file hash, holders and unlock time. Early calls are refused and logged.
  4. ReleaseAt the unlock time, K holders release on-chain. The key is rebuilt in the viewer's browser.
